### Summary (in context of goal: AI Agent)

Hermes Agent is a self‑improving AI agent that builds and refines skills from experience, persists knowledge across sessions, and can be run on cheap cloud resources via a full terminal UI or messaging gateways.

### Key points (from source body)

- It features a built‑in learning loop that creates skills from experience, improves them during use, and persists knowledge by searching past conversations.
- It can run on a $5 VPS, GPU cluster, or serverless infrastructure with near‑zero cost when idle.
- It offers a full terminal UI with multiline editing, slash‑command autocomplete, conversation history, and streaming tool output.
- It is compatible with the agentskills.io open standard and supports autonomous skill creation and cron‑based scheduled automations.
- It works across platforms via Telegram, Discord, Slack, WhatsApp, Signal, and a portable CLI gateway.

### Usage

- Run the provided installer script to set up Hermes on Linux, macOS, WSL2, Termux, or Windows.
- Start the terminal UI with `hermes` or launch the gateway and connect via Telegram, Discord, Slack, etc.
- Select a model using the `/model` command and begin a conversation, using slash commands to manage skills and memory.
